## 📝 27 февраля 2026 — Исправлен баг: платящие клиенты получали демо вместо полных версий

**Проблема:** Клиент оплатил пакет 490₽ (10 генераций), создал генерацию — получил 45-секундное демо вместо полной версии.

**Причина:** `run_monitor_notify.py` всегда отправлял демо для всех пользователей, кроме Admin и Кавера. Не было проверки оплаты.

**Исправление:** Добавлена проверка в `send_telegram_notification()`:
- Если `SELECT COUNT(*) FROM payments WHERE user_id = %s AND status = 'succeeded'` > 0 → полные версии
- Если нет оплат → демо (как раньше)

**Логика:** Пользователи без оплаты получают 45-сек демо → мотивация купить. Пользователи с оплатой получают сразу полные версии — тогда кнопка "Разблокировать (300₽)" не показывается.

**Файл:** `run_monitor_notify.py`
**Деплой:** ✅ Перезапущен albimusic-monitor
