## 🎵 ДЕМО-СИСТЕМА (КРИТИЧЕСКИ ВАЖНО!)

### Как работает:

1. **Celery генерирует музыку:**
   - Suno API возвращает 2 версии песни (sunoData массив)
   - Celery сохраняет в БД как JSON массив: `["url1", "url2"]`
   - Важно: НЕ одну ссылку, а МАССИВ!

2. **Monitor проверяет БД:**
   - Каждые 10 секунд ищет записи с `status='completed'` и `audio_url NOT LIKE 'ALR%'`
   - Если находит запись с 2 ссылками → отправляет ДЕМО

3. **Отправка ДЕМО (45 секунд):**
   - Скачивает оба трека
   - Обрезает через ffmpeg до 45 секунд
   - Отправляет пользователю 2 демо версии
   - Показывает кнопки:
     - 🔓 Разблокировать (1 токен)
     - 📢 Разместить в канале
     - 🔗 Поделиться с другом
     - 🔔 Перейти в канал

4. **Маркировка отправленного:**
   - Monitor помечает запись как `ALREADY_SENT_...` чтобы не отправлять повторно

### ⚠️ ЧТО НЕЛЬЗЯ ДЕЛАТЬ:
- ❌ НЕ отправлять результат из бота напрямую
- ❌ НЕ сохранять только 1 ссылку в БД
- ❌ НЕ изменять формат хранения audio_url
- ❌ НЕ добавлять обработчики отправки результата в bot

## 🎯 Suno API интеграция

### Генерация музыки (`generate_suno_music_sync()`)
**Endpoint:** `POST /api/v1/generate`

**Важно:**
- Возвращает 2 версии (sunoData массив)
- Извлекать ВСЕ audioUrl, не только первый!
- Сохранять как JSON массив: `json.dumps([url1, url2])`

### Генерация текстов (`generate_suno_lyrics_sync()`)
**Endpoint:** `POST /api/v1/lyrics`

**Лимиты:**
- Prompt: макс 200 символов
- Возвращает несколько вариантов
- Брать только первый (лучший)

**Статусы ответа:**
- `'complete'` или `'SUCCESS'` - текст успешно сгенерирован
- `'failed'`, `'ERROR'`, `'GENERATE_LYRIC_FAILED'` - ошибка генерации
- Polling: 30 попыток по 5 секунд (макс 150 сек)

**Обработка ошибок:**
```python
# Проверка статуса покрывает все варианты ошибок
elif status and ('failed' in status.lower() or status == 'ERROR'):
    return None  # Немедленный возврат ошибки
```

**UX при ошибке:**
- Показывается понятное объяснение
- Предлагается переформулировать или написать свой текст
- Пользователь возвращается в главное меню

## 📤 INLINE QUERY HANDLER (Отправить другу)

### Архитектура sharing функции

#### Компоненты:
1. **Inline Query Handler** (main_with_payments.py:1019-1086)
2. **Кнопка в Monitor** (run_monitor_notify.py) - `switch_inline_query`
3. **Кнопка в "Мои треки"** (main_with_payments.py:826-828)

#### Логика работы:

```python
@dp.inline_handler()
async def inline_query_handler(inline_query: InlineQuery):
    # 1. Получаем последние 5 треков пользователя
    tracks = execute_query_sync(
        "SELECT task_id, prompt, audio_url, created_at FROM generations
         WHERE user_id = %s AND status = 'completed'
         ORDER BY created_at DESC LIMIT 5"
    )

    # 2. Формируем InlineQueryResultAudio для каждого трека
    for track in tracks:
        result = InlineQueryResultAudio(
            audio_url=first_audio_url,
            title=f"🎵 {short_prompt}",
            caption=f"🎵 Зацени что я создал!\n\n{prompt}\n\n@AlBimusic_bot"
        )

    # 3. Отправляем результаты с кэшированием 1 сек
    await bot.answer_inline_query(inline_query.id, results=results, cache_time=1)
```

#### Типы результатов:

**InlineQueryResultAudio:**
- `audio_url` - прямая ссылка на MP3 (из `generations.audio_url`)
- `title` - короткое описание (первые 50 символов промпта)
- `caption` - полное описание + приглашение в бота
- `performer` - "ALBI Music"

**InlineQueryResultArticle** (если нет треков):
- Показывает приглашение создать первую песню
- Text-only сообщение с ссылкой на бота

#### Безопасность:

- ✅ Показывает только треки конкретного пользователя (фильтр по `user_id`)
- ✅ Показывает только завершённые треки (`status = 'completed'`)
- ✅ Исключает ошибки (`audio_url NOT LIKE 'ERROR%'`)
- ✅ Лимит 5 треков (производительность)
- ✅ Cache time 1 сек (актуальность данных)

1. **Из Monitor:** Кнопка "🔗 Поделиться с другом" → открывает inline mode

3. **В любом чате:** `@AlBimusic_bot` → показывает свои треки

```python
if not is_unlocked:
    # Если не разблокирован → запрещаем публикацию
    await bot.send_message(
        user_id,
        "❌ Для публикации в канале сначала нужно разблокировать полные версии (1 токен)"
    )
    return

# Если разблокировано → разрешаем публикацию полной версии
audio_url = demo_url
```

## 🧹 АВТОМАТИЧЕСКАЯ ОЧИСТКА ФАЙЛОВ

**Система автоочистки предотвращает засорение сервера**

### 1. Очистка загруженных файлов
**Скрипт:** `cleanup_uploads.py`
- **Директория:** `/var/www/albimusic/uploads/`
- **Расписание:** Каждый час (cron: `0 * * * *`)
- **Правило:** Удаляет файлы старше 1 часа
- **Лог:** `/var/log/albimusic/cleanup.log`
- **Что удаляется:** Аудио файлы загруженные пользователями для кавера/минусовки

### 2. Очистка временных демо файлов
**Директория:** `/tmp/albimusic_demos/`
- **Когда удаляется:** Сразу после отправки пользователю
- **Логика:** В `run_monitor_notify.py` (строки 251-258)
- **Что удаляется:** Обрезанные демо файлы (45 сек)

### 3. Очистка старых записей БД
**Скрипт:** `cleanup_old_records.py`
- **Расписание:** Раз в неделю, воскресенье 3:00 (cron: `0 3 * * 0`)
- **Лог:** `/var/log/albimusic/db_cleanup.log`
- **Что удаляется:**
  - Задачи генерации старше 30 дней
  - Платежи старше 90 дней (только успешные)
  - Логи админа старше 7 дней
- **Оптимизация:** Выполняет VACUUM ANALYZE для оптимизации БД

### 4. Ротация логов
**Система:** logrotate (встроенная в Linux)
- **Директория:** `/var/log/albimusic/`
- **Правило:** Ротация ежедневно, сжатие старых логов (.gz)
- **Хранение:** 7 дней
- **Текущий размер:** ~6.5MB (нормально)
