### Тест 1: Генерация песни с достаточным балансом

**Входные данные:**
1. Пользователь с balance >= 1

- ✅ В БД создается запись со статусом 'pending'

- ✅ Запись в БД обновляется статусом 'completed'

**Проверка в БД:**
```sql

FROM generations 
WHERE user_id = <ID пользователя> 
ORDER BY created_at DESC 
LIMIT 1;
```

## 📊 МОНИТОРИНГ

### Проверка незавершенных генераций

```sql
-- Генерации в статусе pending дольше 10 минут (возможна проблема)
SELECT task_id, user_id, prompt, created_at, status
FROM generations
WHERE status = 'pending' 
  AND created_at < NOW() - INTERVAL '10 minutes'
ORDER BY created_at DESC;
```

### Статистика по статусам

```sql
SELECT status, COUNT(*) as count
FROM generations
GROUP BY status;
```

**Ожидаемый результат после применения:**
```
  status   | count
```
