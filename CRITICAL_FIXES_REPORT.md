### Найденный баг (корневая причина)

**Три функции внутри ЮKassa webhook-хендлера (`main_with_payments.py`) падали при вызове через `asyncio.create_task()`:**

1. **`_send_unlocked_first_gen`** — `NameError: name 'BOT_TOKEN' is not defined`
   Причина: имя `BOT_TOKEN` недоступно в asyncio-задаче, созданной из вложенной функции.
   Исправление: добавлен default-аргумент `_token=BOT_TOKEN`.

2. **`_notify_novice_gen`** — `Timeout context manager should be used inside a task`
   Причина: использование глобального `bot` (его aiohttp-сессия создана вне задачи).
   Исправление: создаётся локальный `_Bot(token=_token, proxy=...)`, закрывается в `finally`.

3. **`_notify_payment`** — `Timeout context manager should be used inside a task`
   Та же причина и исправление, что и `_notify_novice_gen`.
