### ❌ ПРОБЛЕМА #1: Обработчик cover_v1/v2 НЕ списывает баланс
**Локация:** `main_vk.py`, строки ~2169-2199
**Описание:** При выборе версии для кавера баланс НЕ списывается, только показывается меню выбора жанра. Баланс спишется позже в `cover_genre`, что позволяет пользователю многократно выбирать версию.

**Исправление:**
```python
# БЫЛО:
if result and result[0][0] >= 1:
    # Только показываем меню жанров
    from vk_keyboards import get_cover_genre_keyboard
    self.send_message(...)

# ДОЛЖНО БЫТЬ:
if result and result[0][0] >= 1:
    # СНАЧАЛА списываем баланс
    execute_query_sync(
        "UPDATE users SET balance = balance - 1 WHERE user_id = %s",
        (user_id,)
    )
    logger.info(f"💰 Списан 1 токен с баланса пользователя {user_id} ДО выбора жанра")
    
    # ПОТОМ показываем меню
    from vk_keyboards import get_cover_genre_keyboard
    self.send_message(...)
```
